# Multilingual AI Assistant

## 🎯 Problem Statement
Language barriers prevent rural/regional Indian students from accessing tech education. Most content is in English.

## ✨ Solution
An AI-powered platform that translates and simplifies technical concepts using IBM Bob:
- **Translate:** English → Hindi, Tamil, Telugu, Kannada
- **Simplify:** Complex technical content → beginner-friendly language
- **Localize:** Indian student-relevant examples

## 📚 Supported Topics
- Microcontroller basics
- IoT fundamentals
- Embedded systems
- Arduino & sensors

## 🛠️ Tech Stack
- **Frontend:** React + Tailwind CSS
- **Backend:** Node.js + Express
- **AI:** IBM Watson Assistant (Bob)
- **Translation:** Google Translate API

## 🚀 Quick Start

### Backend
```bash
cd backend
npm install
# Add your IBM credentials to .env
npm run dev
```

### Frontend
```bash
cd frontend
npx create-react-app .
npm install
npm start
```

## 📝 Features
- ✅ Multilingual support (5 languages)
- ✅ Real-time translation
- ✅ Student-friendly simplification
- ✅ Responsive UI
- ✅ Copy-to-clipboard
- ✅ Sample questions

## 🎓 Impact
- **Inclusive Education:** Tech education in regional languages
- **Accessibility:** Students learn in their mother tongue
- **Scale:** 700M+ regional language speakers benefit
